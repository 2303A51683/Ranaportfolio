# Mekala Ranadeep — Portfolio

A responsive, single-page developer portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — portfolio content and sections
- `style.css` — responsive visual styling
- `script.js` — mobile navigation and current year

## Run locally
1. Extract the ZIP file.
2. Open the `ranadeep_portfolio` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

No framework or build step is required.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.
